An Android application developed with Java and Material Design that simplifies gift-giving through personalized recommendations and an integrated event reminder system.
Developed as a collaborative project for the Mobile Application Development course at the School of Informatics, Aristotle University of Thessaloniki.

Features
1. Recommendation Engine: Filters gift ideas dynamically based on age, recipient relationship, hobbies, and budget constraints.
2. Event and Reminder Timeline: In-app calendar to track upcoming events, featuring swipe-to-delete management and visual timeline cues.
3. Wishlist: Save, manage, and remove favorite gift recommendations.
4. Authentication and Guest Mode: Option to sign up and log in for permanent data storage, or browse as a guest for instant ideas.
5. Modern UI: Clean interface built with Material Design Components and dynamic Fragment navigation.

Tech Stack:
Language: Java
Framework: Android SDK (API 26+)
Database: SQLite (SQLiteOpenHelper)
Key Components: Material Design Components, RecyclerView, Fragments, SharedPreferences

Setup and Run
1. Clone the repository to your local machine.
2. Open the project in Android Studio.
3. Allow Gradle to sync dependencies.
4. Run the project on an Android Emulator or physical device (Android 8.0+).
